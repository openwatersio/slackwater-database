# Country resolution

Production country lookups use c5y-n8r dataset 6 at immutable commit `3d5e0f52320308fd9e339a7ad40d47ed70d2f09c`, from [c5y-n8r #312](https://github.com/openwatersio/c5y-n8r/pull/312). `packages/database/src/country.ts` opens it once, lazily, and performs namespaced point lookups. The build embeds the same binary into Node, browser and Worker bundles so `buildDatabase()` needs no runtime filesystem or network access. The published package includes the binary, release metadata, evidence companion and upstream notices in `dist/generated/`.

`countryByIso` handles alpha-2, alpha-3 and numeric ISO codes. Names use exact upstream spellings under the registry's normalization rules. Unknown, ambiguous, retired, deprecated and outside-date results remain unresolved. A tentative current answer with explicitly uncertain historical bounds is usable; this does not certify the data or its historical dates. The reader retains the dataset version and uncertainty in the underlying binary.

Source station records preserve their explicit alpha-2 identity. Geocoding, curated location codes, maritime zones and TICON imports pass codes through rather than round-tripping display labels. Country-specific datums and source jurisdictions use codes. The Western Samoa name retains its existing WS compatibility mapping. The published builder accepts recognized aliases for the same code, plus the stored labels `Virgin Islands` paired with VI and `Saint Helena` paired with SH. Those explicit pairs do not create worldwide aliases for the bare names.

The consumer coverage includes all 8,728 stored source records, the 157 country codes in the GeoNames place snapshot, and curated location codes. The complete catalogue comparison retains all 12,396 stations and published routes, with changes confined to country and continent labels. The standalone [migration diagnostic](country-resolver-spike.md) retains its frozen baseline and source-context evidence.

Wikidata's missing metadata remains visible. Åland has no P30 continent claim in the pinned snapshot, tracked in [c5y-n8r #283](https://github.com/openwatersio/c5y-n8r/issues/283). Its AX identity resolves, while its continent remains empty. A fresh source import requiring that absent continent fails for review; production's current station inventory does not require AX as a station identity. Evidence research is asynchronous and does not block admission of faithful existing Wikidata values.
