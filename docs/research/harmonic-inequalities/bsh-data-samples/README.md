# BSH data samples

Datenquelle: Gezeitenvorausberechnungen 2026 ©, Bundesamt für Seeschifffahrt und Hydrographie, Hamburg, 2026

BSH's tide predictions for Cuxhaven, Steubenhöft (506P), downloaded from [gezeiten.bsh.de](https://gezeiten.bsh.de) and converted from Latin-1 to UTF-8. `DE__506P2026-hwnw.txt` is the full high and low water file and `DE__506P2026-kurve-head.txt` the first 40 lines of the 10-minute curve file. BSH permits publishing them with this credit; see the [research notes](../README.md) for the terms.
